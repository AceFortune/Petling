# Petling

Petling is a browser-based virtual pet game.

## Deployment

This repository is ready for static deployment on Vercel.

- Entry point: `index.html`
- Static assets: `assets/`
- No build command is required.
- No framework preset is required.

For Vercel, import this GitHub repository and choose **Other** as the framework if Vercel does not detect a framework automatically. Leave Build Command empty and use the repository root as the Output Directory.
